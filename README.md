# Spendly 💰

Spendly is a personal finance management web application that helps users track their income and expenses in one place.

## Features
- User registration and login
- Add, edit, and delete transactions
- Income and expense categories
- Dashboard with financial overview
- Reports and transaction history
- Currency and theme settings

## Technologies
- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Installation
1. Clone the repository.
2. Import `database/spendly_db.sql` into phpMyAdmin.
3. Configure the database connection in `config.php`.
4. Place the project inside your XAMPP `htdocs` folder.
5. Open the project through `localhost`.
